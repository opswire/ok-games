# ТЗ для Claude Code: пять игр для VK и ОК

Nov 11, 2026 · @Stanislav

## Как пользоваться этим ТЗ

Каждая игра собирается из двух частей: раздел «Общее ТЗ» плюс раздел конкретной игры. Отдавайте их в Claude Code вместе, одним сообщением.

1. Создайте пустую папку под игру и запустите в ней Claude Code.
2. Вставьте текст раздела «Общее ТЗ» и раздела нужной игры. Добавьте фразу: «Сначала составь план по этапам и покажи мне, потом реализуй этап 1».
3. Принимайте работу по этапам из раздела игры. После каждого этапа открывайте игру в браузере в режиме телефона и проверяйте критерии приёмки.
4. Не переходите к следующему этапу, пока текущий не работает без ошибок в консоли.
5. Интеграцию с VK (этап «Платформа») делайте последней: до неё игра должна полностью работать локально с заглушками рекламы.

Порядок разработки: «Банки с вареньем» → «Слова с грядки» → «Угадай по фото» → «Дачные отличия» → «Пасьянс». Первые две игры не требуют картинок и делаются целиком кодом.

Папку «common/» из первой игры копируйте в следующие: обёртка платформы, сохранения, звук и окна переиспользуются без изменений.

## Общее ТЗ для всех игр

Этот раздел — обязательная часть задания для каждой игры. Текст ниже написан как прямое поручение для Claude Code.

### Цель и аудитория

Сделай казуальную HTML5-игру для каталога VK Games (ВКонтакте и Одноклассники). Основной игрок — женщина 40–65 лет, играет с телефона на Android, часто с недорогого. Игра должна быть понятна без обучения за 10 секунд.

### Стек

- Чистые HTML, CSS и JavaScript (ES-модули), без фреймворков и игровых движков. Сборка — Vite.
- Отрисовка: DOM и CSS-анимации; Canvas — только там, где это указано в разделе игры.
- Никаких внешних запросов, кроме VK Bridge. Шрифты, звуки и картинки лежат в проекте.
- Размер сборки до 5 МБ, первый экран появляется быстрее 3 секунд на 4G.
- Результат `npm run build` — папка `dist/` со статикой, готовая к загрузке на хостинг.

### Структура проекта

```
src/
  common/      # переиспользуется во всех играх
    platform.js   # обёртка над VK Bridge + локальная заглушка
    storage.js    # сохранения
    audio.js      # звуки, выключатель
    ui.js         # окна, кнопки, тосты
    analytics.js  # события
  game/        # логика конкретной игры, без обращений к DOM
  screens/     # экраны: меню, игра, победа, магазин, настройки
  data/        # уровни, словари, вопросы (JSON)
  assets/      # графика и звук
tests/         # тесты логики (Vitest)
```

Логика игры в `game/` — чистые функции, покрытые тестами. Экраны только вызывают её и рисуют результат.

### Обёртка платформы (`platform.js`)

Вся работа с соцсетью идёт только через этот модуль. Интерфейс:

| Метод | Что делает |
| --- | --- |
| `init()` | Вызывает `VKWebAppInit`, читает параметры запуска |
| `isRewardedReady()` | `VKWebAppCheckNativeAds` с `ad_format: 'reward'` |
| `showRewarded()` | `VKWebAppShowNativeAds` с `ad_format: 'reward'`; возвращает `true`, только если реклама показана |
| `showInterstitial()` | То же с `ad_format: 'interstitial'` |
| `buy(itemId)` | `VKWebAppShowOrderBox` с `type: 'item'` |
| `save(key, value)` / `load(key)` | `VKWebAppStorageSet` / `VKWebAppStorageGet` |
| `share()` / `invite()` | Поделиться результатом, позвать друзей |

Если игра открыта не внутри VK или ОК (локальная разработка), модуль включает заглушку: реклама — окно «Реклама (тест)» на 2 секунды с успешным результатом, покупки — мгновенный успех, сохранения — `localStorage`. Точные названия методов и параметры сверь с актуальной документацией VK Bridge перед реализацией.

### Реклама

- Rewarded-реклама — только по нажатию игрока на кнопку с понятной наградой («Подсказка за видео»). Награда выдаётся только после успешного показа.
- Если реклама недоступна, кнопка неактивна с подписью «Реклама загружается», игра не ломается.
- Interstitial — не чаще одного раза в 3 минуты, только между уровнями, никогда во время хода. Первые 3 уровня — без interstitial.
- После покупки «Без рекламы» interstitial отключается навсегда, rewarded-кнопки остаются.

### Покупки

- Товары описаны в `data/shop.json`: id, название, цена в голосах, что выдаёт.
- Покупки за голоса требуют серверного обработчика платёжных уведомлений. Сделай его отдельной маленькой функцией в папке `server/` (Node.js, один файл), с проверкой подписи. До подключения сервера магазин работает на заглушке.
- Купленное начисляется сразу и сохраняется; повторный запуск не теряет покупки.

### Сохранения

- Прогресс сохраняется после каждого уровня и каждой траты или получения валюты.
- Запись — и в хранилище платформы, и в `localStorage`; при загрузке берётся запись с большим номером версии.
- В сохранении есть поле `schemaVersion` и функция миграции.

### Интерфейс

- Только вертикальная ориентация; на компьютере — колонка шириной до 480 px по центру с фоном по бокам.
- Основной текст не меньше 18 px, кнопки не меньше 56 px в высоту, зона нажатия не меньше 48×48 px.
- Высокий контраст, цвета игровых элементов различимы при дальтонизме (цвет дублируется узором или значком).
- Никаких таймеров, штрафующих за медлительность, если иное не указано в разделе игры.
- Весь текст на русском, без англицизмов и сленга. Тексты вынесены в `data/strings.json`.
- Звук выключается кнопкой и автоматически — при сворачивании вкладки.
- Обучение: первые 1–2 уровня с подсвеченной рукой-указателем, без длинных текстов.

### Удержание (во всех играх)

- Ежедневный подарок: 7-дневная лента наград, пропуск дня сбрасывает ленту.
- Мягкая валюта «монеты»: выдаётся за уровни, тратится на подсказки.
- После победы — кнопка «Удвоить награду за видео».

### Аналитика

`analytics.track(name, params)` пишет события в консоль и в очередь; отправка подключается позже. Обязательные события: `level_start`, `level_win`, `level_fail`, `hint_used`, `ad_rewarded_shown`, `ad_interstitial_shown`, `purchase`, `daily_bonus`.

### Критерии приёмки (общие)

- [ ] `npm run build` проходит без ошибок, `npm test` — все тесты зелёные.
- [ ] Игра работает в Chrome на Android и в Safari на iPhone, в ширинах от 320 до 480 px.
- [ ] В консоли нет ошибок за полную сессию из 10 уровней.
- [ ] Закрытие и повторное открытие игры возвращает на тот же уровень с той же валютой.
- [ ] При недоступной рекламе и при отказе от покупки игра продолжает работать.
- [ ] Нет чужих картинок, шрифтов, музыки и названий: всё своё или с открытой лицензией, список лицензий — в `LICENSES.md`.

## Игра 1. «Банки с вареньем» — сортировка

Игрок переливает слои варенья между банками, пока в каждой банке не останется один сорт. Срок — 1–2 недели, картинки не нужны.

### Правила

- На поле N банок, каждая вмещает 4 слоя. Слой — один из сортов варенья: клубника, малина, абрикос, смородина, крыжовник, вишня, слива, облепиха, черника, яблоко, груша, брусника.
- Нажатие на банку выбирает её (банка приподнимается), нажатие на вторую — переливает.
- Переливать можно, только если вторая банка пуста или её верхний слой того же сорта и есть место. Переливаются все одинаковые верхние слои подряд, сколько поместится.
- Недопустимый ход: банка покачивается, слой не уходит, штрафа нет.
- Уровень пройден, когда каждая банка пуста или полностью заполнена одним сортом. Собранная банка закрывается крышкой с этикеткой.
- Проигрыша нет. Если ходов не осталось, игра предлагает: отменить ход, добавить банку или начать заново.

### Генератор уровней

- Уровни не хранятся, а строятся по номеру: `generateLevel(n)` с детерминированным генератором случайных чисел (seed = номер уровня). Один и тот же номер всегда даёт один и тот же уровень.
- Способ: взять решённое состояние и сделать K случайных обратных ходов, затем проверить решаемость решателем (поиск в глубину с запоминанием посещённых состояний и лимитом на их число). Нерешаемые или тривиальные (решение короче 5 ходов) — перегенерировать со следующим seed.
- Кривая сложности:

| Уровни | Сортов | Пустых банок | Особенность |
| --- | --- | --- | --- |
| 1–2 | 2 | 1 | Обучение с рукой-указателем |
| 3–10 | 3–4 | 2 | — |
| 11–30 | 5–6 | 2 | — |
| 31–80 | 7–8 | 2 | Каждый 5-й уровень — «секретные» слои |
| 81+ | 9–12 | 2 | Каждый 10-й — сложный, с двойной наградой |

- «Секретные» слои: видны только верхние слои банок, остальные закрыты знаком вопроса и открываются, когда оказываются сверху.
- Каждый уровень после сложного — заметно легче: игрок должен чувствовать передышку.

### Экраны

1. **Главный:** крупная кнопка «Играть — уровень N», ежедневный подарок, магазин, настройки.
2. **Игра:** номер уровня, банки в 1–2 ряда, внизу три кнопки — «Отменить», «Ещё банка», «Заново». На кнопках счётчики запасов.
3. **Победа:** анимация закатанных банок на полке, награда в монетах, кнопки «Удвоить за видео» и «Дальше».
4. **Кладовая (мета):** полки, которые заполняются собранными банками. Каждые 10 уровней открывается новая полка или украшение кладовой. Это витрина прогресса, без отдельной механики.
5. **Магазин и настройки.**

### Отрисовка и ощущения

- Банки и слои — DOM-элементы или SVG, без растровых картинок. У каждого сорта свой цвет и значок ягоды на слое.
- Переливание анимируется: банка наклоняется, струя, слой растёт. Длительность 350–450 мс, во время анимации следующий ход уже можно нажимать (очередь ходов).
- Звуки: бульканье при переливании, щелчок крышки, короткая мелодия победы.

### Монетизация

| Точка | Формат | Что получает игрок |
| --- | --- | --- |
| «Отменить» — запас кончился | Rewarded | +5 отмен |
| «Ещё банка» | Rewarded | +1 пустая банка на этот уровень (не больше двух за уровень) |
| После победы | Rewarded | Удвоение монет |
| Между уровнями, с 4-го | Interstitial | — |
| Магазин | Покупка | «Без рекламы», наборы отмен и банок, набор монет |

Стартовый запас: 5 отмен. Монеты: 10 за уровень, 20 за сложный; 50 монет = 5 отмен.

### Этапы

1. **Логика:** состояние поля, правила хода, проверка победы, отмена, генератор и решатель. Тесты: 500 первых уровней решаемы, генерация уровня быстрее 200 мс.
2. **Игровой экран:** отрисовка, ввод, анимации, обучение.
3. **Обвязка:** главный экран, победа, кладовая, сохранения, ежедневный подарок, звук.
4. **Монетизация:** точки рекламы, магазин на заглушках.
5. **Платформа:** подключение VK Bridge, проверка внутри VK и ОК.

### Критерии приёмки

- [ ] Все уровни с 1 по 500 проходят автоматическим решателем.
- [ ] Уровень 1 проходится новичком без текста обучения меньше чем за 30 секунд.
- [ ] Отмена возвращает поле ровно в предыдущее состояние, включая «секретные» слои.
- [ ] На экране 320 px 14 банок помещаются в два ряда и не обрезаются.
- [ ] Быстрые нажатия подряд не приводят к потере или дублированию слоёв.

## Игра 2. «Слова с грядки» — филворд

Игрок ищет в сетке букв слова на заданную тему, ведя пальцем по соседним клеткам. Срок — около недели, картинки не нужны.

### Правила

- Поле — квадратная сетка букв. Каждая буква принадлежит ровно одному слову, лишних букв нет.
- Слово идёт «змейкой» по соседним клеткам по горизонтали и вертикали, без диагоналей.
- Игрок ведёт пальцем от первой буквы к последней. Верное слово закрашивается своим цветом и вычёркивается из списка; неверное — выделение гаснет без штрафа.
- У уровня есть тема («Огород», «Выпечка», «Грибы»), она показана сверху. Список слов скрыт: видно только количество и длину каждого («5 букв — ●●●●●»).
- Уровень пройден, когда закрашена вся сетка. Проигрыша и таймера нет.

### Словарь

- Файл `data/words.json`: не меньше 60 тем по 25–40 слов. Только существительные в именительном падеже единственного числа, 3–9 букв, общеизвестные.
- Буква «ё» заменяется на «е». Никаких имён собственных, брани, жаргона, устаревших и спорных слов.
- Темы под аудиторию: огород, сад, кухня, выпечка, заготовки, грибы, ягоды, цветы, деревья, птицы, домашние животные, рыбалка, баня, рукоделие, ткани, посуда, мебель, одежда, праздники, погода, профессии, транспорт, музыка, сказки, деревня, море, лес, аптека, школа, спорт.
- Сгенерируй словарь сам, затем прогони скрипт проверки: длина, алфавит, дубликаты внутри темы. Список слов вынеси в отдельный файл, чтобы я мог вычитать его глазами.

### Генератор сеток

- `generateGrid(size, words, seed)`: заполняет сетку словами полностью. Алгоритм — построить случайный гамильтонов путь по сетке (змейка с случайными перестановками), затем нарезать его на отрезки, длины которых равны длинам подобранных слов темы.
- Подбор слов: сумма длин равна числу клеток. Если точного набора нет — взять другой набор слов той же темы.
- Уровни генерируются по номеру детерминированно; одна тема не повторяется ближе чем через 15 уровней.
- Проверка: слово засчитывается только по задуманному пути. Если игрок собрал верное слово другим путём, показывается мягкая подсказка «Слово есть, но лежит иначе», клетки не закрашиваются.

| Уровни | Сетка | Слов |
| --- | --- | --- |
| 1–3 | 3×3 | 2–3 |
| 4–15 | 4×4 | 3–4 |
| 16–50 | 5×5 | 5–6 |
| 51–150 | 6×6 | 7–8 |
| 151+ | 7×7 | 9–11 |

### Экраны

1. **Главный:** «Играть — уровень N», «Слово дня», ежедневный подарок, магазин, настройки.
2. **Игра:** тема, сетка, под ней — строки с точками по длине ненайденных слов, кнопки «Буква» и «Слово».
3. **Победа:** собранный «урожай» (значок темы кладётся в корзину), монеты, «Удвоить за видео», «Дальше».
4. **Слово дня:** одна сетка 6×6 в день, общая для всех (seed = дата). Серия дней подряд показывается на главном экране.
5. **Коллекция:** корзины по темам — сколько уровней каждой темы пройдено.

### Ввод

- Клетки крупные: при сетке 7×7 на ширине 320 px клетка не меньше 40 px.
- Выделение идёт за пальцем; возврат на предыдущую клетку снимает последнюю букву.
- Над сеткой крупно показывается набираемое слово.
- На компьютере работает и протягивание мышью, и последовательные клики.

### Монетизация

| Точка | Формат | Что получает игрок |
| --- | --- | --- |
| «Буква» | Монеты или rewarded | Подсвечивает первую букву ненайденного слова |
| «Слово» | Монеты или rewarded | Открывает одно слово целиком |
| После победы | Rewarded | Удвоение монет |
| Пропущенный день в серии | Rewarded | Восстановление серии «Слова дня» |
| Между уровнями, с 4-го | Interstitial | — |
| Магазин | Покупка | «Без рекламы», наборы монет |

Цены: «Буква» — 20 монет, «Слово» — 60 монет; награда за уровень — 10–25 монет по размеру сетки.

### Этапы

1. **Данные:** словарь, скрипт проверки, файл для вычитки.
2. **Логика:** генератор сеток, проверка выделения, подсказки. Тесты: 1000 первых уровней генерируются, каждая сетка заполнена полностью и проходима.
3. **Игровой экран:** сетка, ввод пальцем и мышью, анимации.
4. **Обвязка:** экраны, «Слово дня», коллекция, сохранения, звук.
5. **Монетизация и платформа.**

### Критерии приёмки

- [ ] В словаре нет слов вне русского алфавита, дубликатов в теме и слов короче 3 букв.
- [ ] Каждый из первых 1000 уровней проходится автоматическим тестом.
- [ ] Одно и то же «Слово дня» выдаётся при одинаковой дате на разных устройствах.
- [ ] Ведение пальцем не прокручивает страницу и не вызывает системных жестов браузера.
- [ ] Подсказка никогда не открывает уже найденное слово.

## Игра 3. «Угадай по фото: СССР» — викторина

Игрок видит картинку и выбирает один из четырёх ответов. Движок делается за 3–4 дня и потом клонируется в серию с другими темами; основная работа — контент.

### Правила

- Раунд — 10 вопросов одной категории. На вопрос — картинка, текст вопроса и 4 варианта ответа крупными кнопками.
- Верный ответ подсвечивается зелёным, неверный — красным с показом правильного. После ответа — короткий факт (1–2 предложения) и кнопка «Дальше».
- Таймера нет. За раунд начисляются звёзды: 1 — за 5 верных, 2 — за 8, 3 — за 10.
- Категории открываются по звёздам: каждая следующая требует на 5 звёзд больше.
- Вопросы в раунде идут в случайном порядке, варианты ответа перемешиваются.

### Контент

- Категории первой версии, по 50 вопросов в каждой (5 раундов): «Предметы быта», «Кухня и продукты», «Техника в доме», «Автомобили и транспорт», «Игрушки», «Школа», «Одежда и мода», «Двор и игры», «Города и курорты», «Профессии».
- Формат `data/questions.json`:

```json
{
  "id": "byt_001",
  "category": "byt",
  "image": "byt/avoska.webp",
  "question": "Как называлась эта сумка?",
  "answers": ["Авоська", "Котомка", "Ридикюль", "Саквояж"],
  "correct": 0,
  "fact": "Сетчатую сумку носили с собой «на авось» — вдруг что-то выбросят в продажу."
}
```

- Claude Code пишет вопросы, варианты и факты, а также файл `image_prompts.md` с описанием каждой нужной картинки. Картинки я создаю сам в генераторе изображений и кладу в `assets/` по указанным именам.
- До появления картинок игра работает с цветной заглушкой, на которой написано имя файла.
- Картинки: WebP, 800×600, до 80 КБ каждая, подгружаются по раунду, а не все сразу.

### Ограничения по контенту (обязательно)

- Только обезличенные предметы и сцены. Никаких кадров из фильмов и мультфильмов, фотографий артистов, политиков и других реальных людей, логотипов и товарных знаков, государственной символики.
- Никакой политики, идеологии и оценок эпохи — только быт и предметы.
- Каждый факт должен быть проверяемым; спорные и «легендарные» факты не использовать. Список фактов вынеси в отдельный файл для моей вычитки.
- Неверные варианты — правдоподобные, того же типа, что верный, и одной длины с ним.

### Экраны

1. **Главный:** сетка категорий с прогрессом в звёздах, ежедневный подарок, «Вопрос дня».
2. **Раунд:** счётчик «3 из 10», картинка, вопрос, ответы, кнопки подсказок «50/50» и «Вторая попытка».
3. **Итог раунда:** звёзды, число верных, «Поделиться результатом», «Следующий раунд».
4. **Альбом:** все верно угаданные предметы с фактами — коллекция, которую хочется заполнить.

### Социальные механики

- «Поделиться результатом»: карточка «Я узнала 9 из 10 предметов из СССР. А ты?» — через `platform.share()`.
- «Вопрос дня»: один вопрос в сутки, общий для всех, с серией дней.
- Таблица лидеров среди друзей по числу звёзд — если платформа отдаёт список друзей; иначе блок скрыт.

### Монетизация

| Точка | Формат | Что получает игрок |
| --- | --- | --- |
| «50/50» | Монеты или rewarded | Убирает два неверных варианта |
| «Вторая попытка» | Монеты или rewarded | Право ответить ещё раз после ошибки |
| Итог раунда | Rewarded | Удвоение монет |
| Открыть категорию досрочно | Rewarded (3 просмотра) или монеты | Категория без нужных звёзд |
| Между раундами, со 2-го | Interstitial | — |
| Магазин | Покупка | «Без рекламы», наборы монет |

### Движок для серии

Вся тема задаётся тремя вещами: `questions.json`, папка картинок, `theme.json` (название, цвета, тексты). Замена этих файлов должна давать новую игру без правки кода — так делаются «Угадай город», «Угадай блюдо», «Угадай растение».

### Этапы

1. **Движок:** загрузка вопросов, раунд, подсчёт звёзд, подсказки. Тесты логики.
2. **Экраны:** на заглушках картинок и 20 тестовых вопросах.
3. **Контент:** 500 вопросов, `image_prompts.md`, файл фактов для вычитки.
4. **Обвязка, монетизация, платформа.**

### Критерии приёмки

- [ ] Скрипт проверки контента: у каждого вопроса 4 разных ответа, `correct` в диапазоне 0–3, есть факт, файл картинки существует или помечен как заглушка.
- [ ] Верный ответ стоит на каждой из четырёх позиций примерно одинаково часто.
- [ ] Смена `questions.json` и `theme.json` даёт рабочую игру без изменения кода.
- [ ] Раунд проходится одной рукой на экране 320 px без прокрутки.
- [ ] Картинки следующего вопроса подгружаются заранее, пауз при переходе нет.

## Игра 4. «Дачные отличия» — найди отличия

Игрок сравнивает две картинки и нажимает на отличия. Код простой; основная работа — уровни, поэтому в задание входит редактор, в котором я сам размечаю отличия.

### Правила

- На экране две картинки одна над другой. На нижней — 5 отличий (с 30-го уровня — 7).
- Нажатие на отличие на любой из двух картинок засчитывает его: место обводится кружком на обеих, счётчик «2 из 5» растёт.
- Промах: короткое покачивание и крестик на месте нажатия. Три промаха подряд — пауза на 2 секунды, чтобы нельзя было тыкать наугад. Жизней и проигрыша нет.
- Картинки можно увеличивать двумя пальцами; обе увеличиваются и двигаются синхронно.
- Таймера в основном режиме нет. Он есть только в отдельном режиме «На скорость» (90 секунд на уровень, +15 секунд за видео).

### Формат уровня

```json
{
  "id": 12,
  "chapter": "vesna",
  "imageA": "levels/012_a.webp",
  "imageB": "levels/012_b.webp",
  "diffs": [
    { "x": 0.31, "y": 0.62, "r": 0.06 },
    { "x": 0.74, "y": 0.18, "r": 0.05 }
  ]
}
```

Координаты и радиус — в долях от ширины картинки, чтобы работать на любом экране. Зона попадания шире видимого отличия: радиус не меньше 0,05.

### Редактор уровней (отдельная страница `editor.html`)

Инструмент только для меня, в сборку игры не попадает.

1. Я загружаю исходную картинку.
2. Обвожу прямоугольником область и выбираю действие: «Стереть» (заливка соседним фоном), «Перекрасить» (сдвиг оттенка), «Отразить», «Вставить заплатку» (загрузить фрагмент из другого файла).
3. Редактор сохраняет изменённую картинку как вариант B и автоматически добавляет отличие с координатами и радиусом.
4. Кнопка «Проверить» сравнивает A и B попиксельно и показывает все области расхождения — их должно быть ровно столько, сколько размечено отличий.
5. Кнопка «Экспорт» выдаёт обе картинки в WebP (800×600, до 90 КБ) и JSON уровня.

### Контент

- Главы по 20 уровней: «Весна на даче», «Огород», «Баня и двор», «Сбор урожая», «Кухня и заготовки», «Зима в деревне». В первой версии — 3 главы, 60 уровней.
- Claude Code готовит `image_prompts.md`: по одному описанию сцены на уровень, в едином стиле — тёплая рисованная иллюстрация, много мелких предметов, без людей на переднем плане и без текста на картинке.
- Исходные картинки я создаю в генераторе изображений; варианты B делаю в редакторе.
- До появления картинок в игре есть 3 тестовых уровня, которые Claude Code рисует сам простыми SVG-сценами.

### Экраны

1. **Главный:** «Играть — уровень N», карта глав с прогрессом, ежедневный подарок, режим «На скорость».
2. **Игра:** счётчик найденных, две картинки, кнопка «Подсказка» со счётчиком запаса.
3. **Победа:** картинка целиком, монеты, «Удвоить за видео», «Дальше». Пройденная картинка попадает в альбом.
4. **Альбом:** пройденные картинки по главам; полная глава даёт награду и рамку.

### Монетизация

| Точка | Формат | Что получает игрок |
| --- | --- | --- |
| «Подсказка» — запас кончился | Rewarded | +1 подсказка (лупа показывает одно отличие) |
| «На скорость» — время вышло | Rewarded | +15 секунд, один раз за уровень |
| После победы | Rewarded | Удвоение монет |
| Открыть следующую главу досрочно | Монеты | Глава без прохождения предыдущей |
| Между уровнями, с 4-го | Interstitial | — |
| Магазин | Покупка | «Без рекламы», наборы подсказок |

Стартовый запас: 3 подсказки. 40 монет = 1 подсказка; награда за уровень — 10 монет.

### Этапы

1. **Игра на тестовых уровнях:** отображение, попадания, промахи, увеличение, подсказка.
2. **Редактор:** все четыре действия, проверка, экспорт.
3. **Обвязка:** главы, альбом, режим «На скорость», сохранения, звук.
4. **Контент:** `image_prompts.md` на 60 уровней; сборка уровней — моя ручная работа.
5. **Монетизация и платформа.**

### Критерии приёмки

- [ ] Нажатие засчитывается одинаково на верхней и нижней картинке, при любом увеличении.
- [ ] Скрипт проверки уровней: файлы существуют, координаты в диапазоне 0–1, зоны отличий не пересекаются.
- [ ] Уровень, экспортированный из редактора, запускается в игре без правок.
- [ ] Увеличение не ломает прокрутку и не вызывает масштабирование всей страницы.
- [ ] Картинки следующего уровня подгружаются во время экрана победы.

## Игра 5. «Пасьянс: Домик в деревне» — пасьянс с обустройством

Игрок проходит расклады пасьянса «Три пика», получает звёзды и тратит их на ремонт старого деревенского дома. Самая большая игра из пяти: 4–6 недель. Начинать после первых четырёх.

### Правила пасьянса («Три пика»)

- На столе расклад из карт рубашкой вверх; открыты только карты, которые ничем не перекрыты. Внизу — колода и одна открытая карта.
- Игрок убирает со стола открытую карту, если она на единицу старше или младше открытой карты внизу, без учёта масти. Туз и король соседние (К–Т–2).
- Убранная карта становится новой открытой. Если ходов нет — игрок берёт карту из колоды.
- Победа: стол пуст. Поражение: колода кончилась, а на столе остались карты.
- Серия ходов без взятия из колоды даёт растущий бонус монет. Каждая оставшаяся в колоде карта после победы — дополнительные монеты.
- Звёзды за уровень: 1 — за победу, 2 — если в колоде осталось 3+ карты, 3 — если 6+.

### Уровни

- Расклад задаётся формой (`data/layouts.json`): список позиций карт с координатами, слоем и перекрытиями. Нужно 15 форм: три пика, пирамида, ромб, веер, две башни и другие.
- Карты раздаются детерминированно по номеру уровня. Генератор проверяет, что уровень проходим решателем; для уровней 1–20 — что он проходим «жадной» стратегией без подсказок.
- Размер колоды задаёт сложность:

| Уровни | Карт на столе | Карт в колоде | Особые карты |
| --- | --- | --- | --- |
| 1–5 | 10–15 | 20 | Обучение |
| 6–30 | 18–24 | 18–20 | — |
| 31–80 | 24–28 | 16–18 | Замок и ключ |
| 81+ | 28–32 | 14–16 | Замок, лёд, джокер на столе |

- Особые карты: «замок» открывается, когда убрана карта-ключ; «лёд» требует двух попаданий; «джокер» кладётся на любую карту.

### Мета: обустройство дома

- История простая: героиня получила в наследство заброшенный дом в деревне. Короткие реплики соседки-рассказчицы в 1–2 строки, без длинных диалогов.
- Дом разбит на зоны: крыльцо, кухня, горница, спальня, баня, сад, огород, беседка. В каждой зоне 8–12 задач («Починить ступени — 1 звезда», «Покрасить ставни — 2 звезды»).
- Для заметных предметов игрок выбирает один из трёх вариантов вида (например, три цвета ставен). Выбор можно поменять позже за монеты.
- Зоны описаны в `data/home.json`: задачи, цена в звёздах, порядок, варианты вида, слой и координаты спрайта.
- Графика дома — слои PNG/WebP поверх фона зоны. Claude Code готовит `image_prompts.md` со списком всех спрайтов и их размерами; до готовности графики используются подписанные цветные заглушки.
- Первая версия: 3 зоны, 30 задач, 100 уровней.

### Экономика

| Параметр | Значение |
| --- | --- |
| Жизни | 5, одна тратится при поражении, восстановление — 1 за 20 минут |
| Награда за уровень | 1–3 звезды и 20–60 монет |
| +5 карт в колоду при поражении | 150 монет или видео (один раз за уровень) |
| Джокер | 100 монет |
| Отмена хода | 50 монет |
| Стартовый запас | 300 монет, 2 джокера, 3 отмены |

Все числа — в `data/economy.json`, чтобы менять баланс без правки кода.

### События

- Еженедельное событие «Ярмарка»: за 3 дня пройти 15 особых уровней, награда — уникальное украшение для дома.
- Сезонные оформления (Новый год, Масленица, Пасха, дачный сезон) задаются файлом темы и датами в `data/events.json`.

### Экраны

1. **Дом:** текущая зона, список задач со звёздами, кнопка «Играть — уровень N», жизни, монеты, звёзды.
2. **Пасьянс:** стол, колода, счётчик серии, кнопки «Отмена» и «Джокер».
3. **Победа и поражение:** звёзды и монеты; при поражении — «+5 карт за видео» или «Заново».
4. **Магазин, ежедневный подарок, событие, настройки.**

### Монетизация

| Точка | Формат | Что получает игрок |
| --- | --- | --- |
| Поражение | Rewarded или монеты | +5 карт в колоду |
| Жизни кончились | Rewarded | +1 жизнь |
| После победы | Rewarded | Удвоение монет |
| Ежедневный подарок | Rewarded | Вторая награда |
| Магазин | Покупка | Наборы монет (4 размера), «Стартовый набор» со скидкой один раз, «Бесконечные жизни на 24 часа», «Без рекламы» |
| Между уровнями, с 6-го | Interstitial | — |

Здесь покупки — основной источник дохода, поэтому серверный обработчик платежей из общего ТЗ обязателен до публикации.

### Отрисовка

Стол пасьянса — Canvas (много карт и анимаций), дом и интерфейс — DOM. Карты — собственный рисунок: крупные индексы, 4 масти различаются и цветом, и формой. Раздача, переворот и полёт карты анимированы, 60 кадров в секунду на среднем Android.

### Этапы

1. **Логика пасьянса:** правила, расклады, особые карты, генератор и решатель, тесты на 300 уровней.
2. **Экран пасьянса:** Canvas, ввод, анимации, обучение.
3. **Мета:** дом на заглушках, задачи, выбор вариантов, история.
4. **Экономика:** жизни, монеты, магазин, ежедневный подарок.
5. **События и сезонные темы.**
6. **Графика, монетизация, сервер платежей, платформа.**

### Критерии приёмки

- [ ] Первые 300 уровней проходимы решателем; уровни 1–20 — «жадной» стратегией.
- [ ] Жизни восстанавливаются по реальному времени, в том числе пока игра закрыта; перевод часов на устройстве не даёт лишних жизней сверх максимума.
- [ ] Изменение чисел в `economy.json` меняет баланс без правки кода.
- [ ] Выбранные варианты вида предметов сохраняются между сессиями.
- [ ] Покупка начисляется ровно один раз, даже при обрыве связи и повторном уведомлении от платформы.

## Публикация и чек-лист перед модерацией

### Финальная проверка каждой игры

- [ ] Пройдены все общие критерии приёмки и критерии из раздела игры.
- [ ] Rewarded-реклама показывается и выдаёт награду; при отказе досмотреть награды нет.
- [ ] Тестовая покупка проходит, товар начисляется, повторный запуск его не теряет.
- [ ] Прогресс переносится между телефоном и компьютером одного аккаунта.
- [ ] Звук останавливается при сворачивании.
- [ ] В игре нет чужих названий, персонажей, музыки и картинок.
- [ ] Сборка весит меньше 5 МБ, первый экран — быстрее 3 секунд.

### После запуска

Через 2–4 недели сравните игры по трём числам: возврат на 1-й день, возврат на 7-й день, доход на одного игрока в день. Развивайте ту, у которой лучше возврат на 7-й день: новые уровни, события, покупки. Остальные оставьте работать как есть.
