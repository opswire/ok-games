# Лицензии и происхождение материалов

## Игровые материалы

- Банки, ягоды, кухня, кладовая, украшения и остальная графика созданы кодом SVG/CSS специально для этой игры. Сторонние изображения и шрифты не используются.
- Звуки синтезируются Web Audio API в `src/assets/sounds.js`. Сторонние звукозаписи и музыка отсутствуют.
- Тексты, уровни, иконки и оформление созданы для проекта «Банки с вареньем».
- Системный шрифт: `-apple-system`, Segoe UI, Roboto, Helvetica Neue, Arial. Файлы шрифтов в сборку не включены и с внешних серверов не загружаются.

## Библиотека времени выполнения

- **VK Bridge 3.0.2** (`@vkontakte/vk-bridge`) — VK, лицензия MIT. Используется только для связи с VK Games и Одноклассниками; код включается в сборку Vite.
  - https://github.com/VKCOM/vk-bridge
  - https://github.com/VKCOM/vk-bridge/blob/master/LICENSE

## Инструменты разработки

Vite, Vitest и Playwright используются только для сборки и проверок и не входят в клиентскую игру как сторонний игровой код. Их лицензии находятся в пакетах `node_modules` и в lock-файле зависимостей.
