# «Банки с вареньем» — скриншоты для ревью интерфейса

Казуальная головоломка-сортировка для каталога VK Games (ВКонтакте и Одноклассники). Игрок переливает слои варенья между банками, пока в каждой не останется один сорт.

**Аудитория:** женщины 40–65 лет, телефоны на Android, часто недорогие. Игра должна быть понятна без обучения за 10 секунд.

**Требования ТЗ к интерфейсу:**
- только вертикальная ориентация;
- основной текст не меньше 18 px;
- кнопки не ниже 56 px, зона нажатия не меньше 48×48 px;
- цвет всегда дублируется значком (различимость при дальтонизме);
- весь текст на русском, без англицизмов;
- никаких таймеров;
- вся графика своя и нарисована кодом (SVG и Canvas), без растровых картинок: банки, варенье, крышки, обои, полки.

**Готовность:** сделаны этапы 1–3 из 5 (логика, игровой экран, обвязка) и обновлена графика. Реклама, магазин и подключение VK — следующие этапы.

**Что изменилось с прошлого ревью:**
- новая графика банок: стекло с бликами, варенье с объёмом и кусочками ягод, крышка из ткани с бечёвкой;
- переливание на Canvas: варенье в наклонённой банке остаётся горизонтальным, струя, волна, брызги, искры над собранной банкой;
- исправлены все замечания прошлого ревью: собранная банка больше не прячет слои под «?», на 320 px до трёх рядов банок, плашки уровня отдельной строкой, ничего не обрезается.

**Как сняты:** Chrome, режим телефона, плотность пикселей ×2. Две ширины: 360×780 (типичный Android) и 320×568 (самый узкий экран из ТЗ). Каждый кадр снят на обеих ширинах, файлы начинаются с `360px-` или `320px-`.

## Что заведомо не сделано (будет на этапе 4)

- Значок видео на кнопках «Отменить» и «Ещё банка» уже нарисован, но реклама не подключена: банка сейчас выдаётся бесплатно, а в окне «Отмены закончились» (кадр 13) варианта «за видео» пока нет.
- «Подсказка» при нехватке монет просто гаснет; вариант «за видео» появится вместе с рекламой.
- На экране победы нет кнопки «Удвоить награду за видео».
- Нет магазина и покупки «Без рекламы».
- Звук есть (синтез Web Audio), но на скриншотах его не видно.

## Где нужно мнение проверяющего

1. Стала ли игра привлекательнее: банки, варенье, кухня (кадры 02, 05, 10, 14).
2. Читается ли переливание как настоящее (кадры 06a–06c).
3. Различимы ли сорта по цвету и значку на 320 px при 16 банках (кадр 12).
4. Нет ли проблем с читаемостью и контрастом для пожилой аудитории.
5. Насколько живыми ощущаются экраны победы и кладовой как награда за прогресс.
