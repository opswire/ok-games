# Банки с вареньем

Мобильная HTML5-игра-сортировка для VK Games и Одноклассников. Чистые JavaScript, DOM/SVG/CSS, Vite; игровая логика отделена от экранов.

## Запуск и проверка

Требуется Node.js 20.19+ или 22.12+.

```bash
npm ci
npm run dev                 # http://localhost:5173
npm run check               # unit-тесты + production-сборка
npm run preview -- --port 4173
```

Браузерные проверки требуют установленный Google Chrome и запущенный сервер:

```bash
npm run test:browser        # сначала dev-сервер на порту 5173
# либо против production-сборки:
node scripts/smoke.js http://localhost:4173/
node scripts/release-check.js http://localhost:4173/
```

Полезные адреса: `/?level=35` открывает уровень напрямую, `/?level=12&slowmo=10` замедляет анимацию. Награда за повторное прохождение через такой адрес не начисляется.

## Что реализовано

- Детерминированные уровни с решателем; первые 500 проверены тестами.
- Переливания с очередью быстрых нажатий, точная отмена, подсказки, тупики, дополнительные банки.
- Секретные слои и дополнительные механики, обучение, адаптивное поле на 320–480 px.
- Главный экран, победа, кладовая, задания, оформление, ежедневные подарки.
- Локальные и платформенные сохранения с версиями и миграциями.
- Rewarded за отмены, банки и удвоение награды; interstitial с ограничением по времени.
- Магазин, товар «Без рекламы», локальные заглушки и VK Bridge.
- Платёжный HTTP-обработчик с подписью и защитой от повторного начисления.
- Современная и legacy-сборки; внешние шрифты, картинки и звуки не запрашиваются.

## Деплой игры

1. Выполнить `npm ci && npm run check`.
2. Загрузить содержимое `dist/` на статический HTTPS-хостинг. Адрес игры в кабинете VK должен вести на `index.html`.
3. Отдавать `index.html` без длительного кэша. Файлы в `dist/assets/` содержат хэш и подходят для долгого immutable-кэша.
4. Разрешить отображение игры в iframe VK/ОК: не отправлять `X-Frame-Options: DENY` или `Content-Security-Policy: frame-ancestors 'none'`.
5. Проверить адрес по HTTPS напрямую и затем внутри обеих платформ.

`base: './'` позволяет разместить игру и в корне домена, и во вложенной папке. Внешние серверы для статики не нужны.

## Платёжный сервер

Клиент вызывает `VKWebAppShowOrderBox`. Товары и цены находятся в `src/data/shop.json`; сервер читает тот же файл, поэтому расхождения цен не будет.

Запуск:

```bash
VK_APP_SECRET='защищённый_ключ_приложения' \
VK_APP_ID='идентификатор_приложения' \
PAYMENTS_DB_PATH='/путь/на/постоянном/диске/orders.json' \
PORT=3000 \
npm run server
```

В кабинете приложения указать публичный HTTPS-адрес `POST /payments`. `GET /health` предназначен для проверки состояния.

- Секрет нужен только серверу; не добавляйте его в клиент, репозиторий или `dist/`.
- Для файла заказов нужен постоянный диск и один процесс обработчика. Повторное уведомление получает прежний ответ, тестовые и боевые заказы разделены.
- Не использовать временную файловую систему serverless-функции как базу заказов. При горизонтальном масштабировании заменить JSON-файл на транзакционную БД с уникальным ключом заказа.
- После смены товаров проверить тестовую покупку; цена в уведомлении должна совпасть с `shop.json`.

## Обязательная проверка перед модерацией

Локальные заглушки не доказывают работу платформенных функций. На реальном телефоне в VK и ОК нужно проверить:

- инициализацию и загрузку без ошибок;
- сохранение прогресса между телефоном и компьютером одного аккаунта;
- rewarded: награда после полного показа и её отсутствие после отказа;
- interstitial не раньше 4-го уровня и не чаще одного раза в 3 минуты;
- тестовую покупку, повторный запуск и отказ от оплаты;
- отключение interstitial после «Без рекламы»;
- звук и его остановку при сворачивании;
- Safari на iPhone и Chrome на Android, включая старые устройства из требований каталога.

Также для карточки каталога нужны ваши иконка, обложка, скриншоты и описание. Сведения об авторских материалах и библиотеке — в `LICENSES.md`.
